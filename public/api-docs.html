Response & safety notes

Errors: JSON endpoints normally return {"error":"message"} with an appropriate HTTP status such as 400, 429, 502 or 503.
Privacy: destination traffic is sent through the selected public proxy, but NekoRoute does not guarantee anonymity or zero trace at host/provider layers.
Preview: create a session with the API, then use the returned frameUrl on this NekoRoute origin. Sessions expire automatically.
Scanner: results are defensive indicators, not a guarantee that a domain is safe or malicious.
